# ReceiptPilot Web お試し版 要件定義

- プロジェクト名: ReceiptPilot Web お試し版
- 作成日: 2026-10-20
- 作成者: 山本 喜一郎(Claude Code と作成)
- 前提(2026-10-20 決定)
  - 目的: ポートフォリオを見た依頼主が、**リンクを開くだけで**操作を体験できるようにする
  - 扱うのは**架空レシートだけ**。本物のレシート・APIキー・AI の読み取りは扱わない
    (「本物のレシートは手元の Mac だけで処理する」という原則は変えない)
  - 公開先: Streamlit Community Cloud(無料。GitHub の公開リポジトリから配信)

---

## ステップ1: 基本動作(ハッピーパス)

### 1-1. 正常系のゴール(1文)

> **公開URLを開くと、架空レシート7枚が読み取り済みの状態で画面が出て、確認・確定・ルール採用・CSVダウンロードまでを、インストールなしで体験できる。**

### 1-2. 合格条件

- [ ] URLを開くだけで画面が出る(ログイン・インストール不要)
- [ ] 最初に「架空データのお試し版であること」と「本物は Mac 版で」という案内が出る
- [ ] 確認・確定・削除・ルール候補の採用・ルールの追加削除・CSVダウンロードが、Mac 版と同じように動く
- [ ] 訪問者ごとにデータが分かれ、他の人の操作が見えない・混ざらない
- [ ] 写真の取り込み・APIキーの設定・AI の読み取り・終了ボタン・データの保存場所は出さない
- [ ] 「最初の状態に戻す」でいつでもやり直せる

### 1-3. 最小構成

- 画面は Mac 版と同じ `app/streamlit_app.py` を使い、環境変数 `RECEIPTPILOT_WEB_DEMO=1` で
  お試し版の動きに切り替える。公開用の入口 `app/web_demo.py` がこの切り替えをして本体を呼ぶ
- データは訪問者(画面のセッション)ごとに一時フォルダへ作る

## ステップ2: リスクの列挙(6観点)

| # | 観点 | ①何が | ②なぜ起きる | ③起きると何が困るか |
|---|---|---|---|---|
| W1 | 入力 | 訪問者が本物のレシートや個人情報をアップロードする | 「使える」と思って入れる | 公開サーバーに個人情報が残る |
| W2 | 入力 | 店名やルールに悪意のある文字列を入れる | 誰でも触れる | 画面の崩れ・CSV で数式が実行される |
| W3 | 外部依存 | API が勝手に呼ばれて費用が発生する | APIキーが設定される・入力される | 山本さんへの課金 |
| W4 | 外部依存 | 公開先が一時停止する(しばらく誰も来ないと休止する) | Streamlit Community Cloud の仕様 | 初めて開いた人が待たされる・止まって見える |
| W5 | タイミング | 複数の訪問者が同時に操作する | 公開URL | 他人の操作が混ざる |
| W6 | 状態 | 訪問者ごとの一時データがたまり続ける | セッションが終わっても消えない | ディスクがあふれて止まる |
| W7 | 状態 | 再読み込みで状態が消える | セッションが変わる | 体験の途中で最初に戻る |
| W8 | 境界 | 大勢が同時に開く | 紹介されて人が集まる | メモリ上限(約1GB)で落ちる |
| W9 | 環境 | Mac 専用の機能(キーチェーン・Finder・終了)が Linux で動かない | 公開先は Linux | エラーで画面が出ない |
| W10 | 環境 | 公開リポジトリに本物のデータや秘密が入る | 公開先は GitHub から配信 | 漏えい |

## ステップ3: 対応判断(確率 × 影響)

| # | リスク | 確率 | 影響 | リスク値 | 方針 | 具体的にどうするか |
|---|---|---|---|---|---|---|
| W1 | 本物のアップロード | 中 | 大 | **高** | 4 | **アップロード機能そのものを出さない**(回避) |
| W2 | 悪意のある文字列 | 低 | 小 | 低 | 1 | 既存の CSV 数式対策のまま。入力はその人のセッションにしか残らない |
| W3 | API の課金 | 低 | 大 | 中 | 4 | お試し版では AI の読み取りを一切呼ばない(APIキーを読まない・設定画面を出さない)。公開先にも APIキーを置かない |
| W4 | 休止 | 高 | 小 | 中 | 3 | **受容**。README に「休止中なら起動ボタンを押して30秒ほど待つ」と書く |
| W5 | 同時操作 | 中 | 中 | 中 | 1 | 訪問者(セッション)ごとに別の一時フォルダを使う |
| W6 | 一時データの蓄積 | 中 | 中 | 中 | 1 | 新しい訪問者が来たとき、6時間以上たった一時フォルダを消す |
| W7 | 再読み込みで消える | 中 | 小 | 低 | 3 | **受容**。お試し版なので、最初からやり直せれば十分 |
| W8 | 大勢の同時アクセス | 低 | 中 | 低 | 3 | **受容**。ポートフォリオ用で、アクセスは多くない想定 |
| W9 | Mac 専用機能 | 高 | 大 | **高** | 1 | お試し版ではキーチェーン・Finder・終了ボタン・自動終了を使わない。自動テストは Linux(CI)でも通す |
| W10 | 秘密・本物のデータ | 低 | 大 | 中 | 1 | 既存の .gitignore(data/・private/)のまま。公開前に差分を確認する |

### 今回「あえて対応しないもの」

- 本物のレシートでの読み取り体験(W1・W3 のため。Mac 版で行う)
- ログイン・利用者ごとの保存(お試し版には不要)
- 休止・再読み込みでの状態の消失(W4・W7)
- アクセスの集中への備え(W8)

## まとめ

- 合格条件: URL を開くだけで、架空レシートで確認〜CSV ダウンロードまで体験できる。訪問者ごとに独立
- 対策: W2, W5, W6, W9, W10 / 回避: W1(アップロードなし)、W3(AI を呼ばない)
- 受容: W4, W7, W8
